搜索语法

默认用空格连接多个条件（AND）。顶部搜索同时作用于全局清单和层级浏览；状态、优先级、标签及日期选择项会继续叠加。

报名 教师
同时包含“报名”和“教师”
"结构化 面试"
匹配完整短语
TODO | NEXT
OR 查询；也可写成 TODO OR NEXT
报名 -宁波
包含“报名”，但排除“宁波”
/教师|事业单位/i
正则表达式；支持 i、m、s、u 标志
grep:/CLOSED:.*2026-07/i
对标题、正文、属性和日期组成的完整文本执行正则
title:考试 tag:工作
字段搜索，可用 title、body、tag、file、path
status:TODO priority:A
按 Org 状态与优先级搜索
prop:ORG_GTD=Calendar
按 Org 属性搜索
level:1..3
只匹配 H1 到 H3
deadline:2026-07-01..2026-07-31
日期闭区间
scheduled:<2026-08-01
日期比较，支持 >、>=、<、<=
closed:today
支持 today、yesterday、tomorrow
has:deadline overdue:true
判断是否存在日期或是否逾期

组合示例

status:TODO deadline:2026-07-01..2026-07-31 -tag:归档 file:org-gtd-tasks.org grep:/面试|笔试/i closed:>=2026-07-01 closed:<=2026-07-31

Org 格式速查

      

        
这是内置的离线速查。星号必须从行首开始；星号数量就是标题层级。

        

          
* 一级标题
** 二级标题
标题与层级。子标题比父标题多一个星号。

          
* TODO [#A] 准备材料 :工作:重要:
状态、优先级和标签。优先级常用 A、B、C。

          
SCHEDULED: <2026-07-30 Thu 09:00>
DEADLINE: <2026-07-31 Fri 18:00>
CLOSED: [2026-07-31 Fri 17:30]
计划、截止与完成时间。尖括号是活动时间戳，方括号常用于完成记录。

          
* CNCL 取消事项
CLOSED: [2026-07-30 Thu 09:45]
CNCL 表示已取消，也按已完成处理。其他状态可在设置中添加。

          
:PROPERTIES:
:OWNER: 张三
:ORG_GTD: Calendar
:END:
属性抽屉。属性名写在两个冒号之间。

          
- [ ] 未完成
- [X] 已完成
1. 有序列表
项目符号、复选框和有序列表。

          
*粗体* /斜体/ _下划线_
=代码= ~原样文字~
行内强调格式。标记符与文字之间不要留空格。

          
[[https://example.com][说明文字]]
链接。也可以写成 [[地址]]。

          
| 名称 | 状态 |
|------+------|
| 示例 | TODO |
表格。每行以竖线开头。

          
#+BEGIN_SRC python
print("hello")
#+END_SRC
代码块与其他指令。编辑器的彩色高亮只改变显示，不改变原文。

        

      

    

  

  

    

      
基础 Vim 操作说明

      

        
这是为 Org 编辑器准备的轻量 Vim 模式，不是完整 Vim。开启后默认进入普通模式，按 i 进入插入模式，按 Esc 返回普通模式。

        

          
h / j / k / l
左、下、上、右移动；连续按 j/k 时编辑器滚动条会跟随光标。

          
i / a
在光标位置／光标后一位进入插入模式。

          
0 / $
移动到当前行开头／结尾。

          
w / b
移动到下一个词／上一个词。

          
x / dd
删除当前字符／删除当前整行。

          
gg / G
跳到文件开头／文件结尾。

          
o / O
在当前行下方／上方新建一行并进入插入模式。

          
/
把焦点移到上方搜索框。

          
:
在编辑器底部调出命令行。

          
:w / :wq
写回但不关闭／写回并关闭；仍会显示原有写回确认。

          
:q / :q!
关闭编辑器。尚未写回的页面内修改不会自动保存到文件。

          
:60
跳转到第 60 行；数字超过文件总行数时会定位到最后一行。

          
:%s/旧/新/g
替换编辑器中的全部匹配文字。

          
:set number
显示行号；使用 :set nonumber 隐藏行号。

          
:help
再次打开本说明。

Org 自定义状态

          
默认状态为 TODO、NEXT、DONE、CNCL。状态只能使用大写字母、数字、下划线或连字符。

          

            
            
          

        

        

          
配置备份

          
导出搜索历史、自定义清单、显示设置、排序、状态、最近打开位置及 WebDAV 连接记录。

          

            

          
为安全起见，导出的 WebDAV 记录不包含密码；文件访问权限和文件内容也不会被导出。

        

        

          
WebDAV

          
从 WebDAV 文件夹读取全部 .org 文件并写回。电脑使用“启动Org清单-WebDAV.cmd”；手机和电脑连接同一 Wi‑Fi 后，使用“启动Org清单-手机WebDAV.cmd”，再在手机打开窗口显示的地址。

          
直连模式
            
WebDAV 服务器必须主动允许跨域访问。
