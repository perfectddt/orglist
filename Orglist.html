搜索语法

默认用空格连接多个条件（AND）。顶部搜索同时作用于全局清单和层级浏览；状态、优先级、标签及日期选择项会继续叠加。

报名 教师
同时包含“报名”和“教师”
"结构化 面试"
匹配完整短语
TODO | NEXT
OR 查询；也可写成 TODO OR NEXT
报名 -宁波
包含“报名”，但排除“宁波”
/教师|事业单位/i
正则表达式；支持 i、m、s、u 标志
grep:/CLOSED:.*2026-07/i
对标题、正文、属性和日期组成的完整文本执行正则
title:考试 tag:工作
字段搜索，可用 title、body、tag、file、path
file:inbox.org,nextactions.org
限定在多个文件中搜索；逗号分隔，命中任一文件即可
file:all
搜索所有文件；不写 file: 时默认也是所有文件，也可写成 file:*
status:TODO priority:A
按 Org 状态与优先级搜索
prop:ORG_GTD=Calendar
按 Org 属性搜索
level:1..3
只匹配 H1 到 H3
deadline:2026-07-01..2026-07-31
日期闭区间
scheduled:<2026-08-01
日期比较，支持 >、>=、<、<=
closed:today
支持 today、yesterday、tomorrow
modified:today
按 Org 的 MODIFIED 属性搜索；也支持 7d、30d、具体日期和日期范围
has:deadline overdue:true
判断是否存在日期或是否逾期
has:countdown countdown:next30d
筛选倒计时；支持 today、active、overdue、next7d、next30d、pinned 和日期范围

组合示例

status:TODO deadline:2026-07-01..2026-07-31 -tag:归档 file:org-gtd-tasks.org grep:/面试|笔试/i file:inbox.org,nextactions.org 报名 -宁波 closed:>=2026-07-01 closed:<=2026-07-31 countdown:next30d tag:考试 modified:7d file:inbox.org

Org 格式速查

      

        
这是内置的离线速查。星号必须从行首开始；星号数量就是标题层级。

        

          
* 一级标题
** 二级标题
标题与层级。子标题比父标题多一个星号。

          
* TODO [#A] 准备材料 :工作:重要:
状态、优先级和标签。优先级常用 A、B、C。

          
SCHEDULED: <2026-07-30 Thu 09:00>
DEADLINE: <2026-07-31 Fri 18:00>
CLOSED: [2026-07-31 Fri 17:30]
计划、截止与完成时间。尖括号是活动时间戳，方括号常用于完成记录。

          
* CNCL 取消事项
CLOSED: [2026-07-30 Thu 09:45]
CNCL 表示已取消，也按已完成处理。其他状态可在设置中添加。

          
:PROPERTIES:
:OWNER: 张三
:MODIFIED: [2026-08-20 Thu 21:15]
:ORG_GTD: Calendar
:END:
属性抽屉。属性名写在两个冒号之间；Orglist 修改条目时会自动更新 MODIFIED。

          
* NEXT 每天阅读
SCHEDULED: <2026-08-11 Tue .+1d>
:PROPERTIES:
:STYLE: habit
:END:
Org Habit。.+ 按实际完成日顺延，++ 保持固定周期；在页面点完成会记录历史并续期。

          
* NEXT 农历生日
<%%(diary-chinese-anniversary 8 15)>
农历周年。两个数字分别是农历月和日，不要再添加 :STYLE: habit。

          
- [ ] 未完成
- [X] 已完成
1. 有序列表
项目符号、复选框和有序列表。

          
*粗体* /斜体/ _下划线_
=代码= ~原样文字~
行内强调格式。标记符与文字之间不要留空格。

          
[[https://example.com][说明文字]]
链接。也可以写成 [[地址]]。

          
| 名称 | 状态 |
|------+------|
| 示例 | TODO |
表格。每行以竖线开头。

          
#+BEGIN_SRC python
print("hello")
#+END_SRC
代码块与其他指令。编辑器的彩色高亮只改变显示，不改变原文。

        

      

    

  

  

    

      
Vim 操作说明

      

        
内置轻量 Vim 开启后默认进入普通模式，按 i 进入插入模式，按 Esc 返回普通模式。你也可以在“设置 → 插件”导入兼容的高级 Vim 编辑器插件。

        

          
h / j / k / l
左、下、上、右移动；连续按 j/k 时编辑器滚动条会跟随光标。

          
v
进入字符选择模式；继续用 h/j/k/l、w/b、0/$、gg/G 扩展选择，按 d 或 x 删除，按 c 删除后进入插入模式，再按 v 或 Esc 退出。

          
手机软键盘
普通模式下英文按键会执行命令，不会写入正文；点击“Esc／普通模式”可从插入模式返回。

          
i / a
在光标位置／光标后一位进入插入模式。

          
0 / $
移动到当前行开头／结尾。

          
w / b
移动到下一个词／上一个词。

          
x / dd
删除当前字符／删除当前整行。

          
gg / G
跳到文件开头／文件结尾。

          
o / O
在当前行下方／上方新建一行并进入插入模式。

          
/
把焦点移到上方搜索框。

          
:
在编辑器底部调出命令行。

          
:w / :wq
写回但不关闭／写回并关闭；仍会显示原有写回确认。

          
:q / :q!
关闭编辑器。尚未写回的页面内修改不会自动保存到文件。

          
:60
跳转到第 60 行；数字超过文件总行数时会定位到最后一行。

          
:%s/旧/新/g
替换编辑器中的全部匹配文字。

          
:set number
显示行号；使用 :set nonumber 隐藏行号。

          
:help
再次打开本说明。

默认筛选条件

          
每次重新打开一批 Org 文件时自动采用这些条件。即使设置了启动页，默认状态、优先级、排序、日期字段和布局仍优先于启动页中曾保存的筛选。

          

            
            
            
            
            
            
          

          

          

        

        

          
新增条目默认项

          
条目详情打开时，新条目默认放在该条目下面；否则层级浏览使用当前层级。这里的设置用于控制其他视图中的默认位置。

          

            
          

        

        

          
四象限默认定义

          
这里保存的规则会作为四象限的默认判断方式；进入四象限后仍可临时调整。

          

            
            
          

        

        

          
启动页

          
启动页只决定打开的视图、文件、层级位置或日历位置；状态、优先级、排序、日期字段和布局始终采用“默认筛选条件”。

          

            

          
当前使用“默认筛选条件”作为启动页。

        

        

          
Org 自定义状态

          
默认状态为 TODO、NEXT、DONE、CNCL。状态只能使用大写字母、数字、下划线或连字符。

          

            
            
          

        

        

          
配置备份

          
导出搜索历史、自定义清单、显示设置、排序、状态、最近打开位置及 WebDAV 连接记录。

          

            

          
为安全起见，导出的 WebDAV 记录不包含密码；文件访问权限和文件内容也不会被导出。

        

        

          
Windows 后台提醒

          
浏览器关闭后仍可提醒。首次使用请双击同目录的 OrglistReminderSetup.cmd 安装 Windows 登录启动项；此处设置需通过 OrglistWebDAV.cmd 打开的页面保存。

提醒时间与 Org 闹钟属性

            
            
            
            

              
SCHEDULED 提前提醒相对计划开始时间提前触发；填 0 表示开始时提醒。

                

              
DEADLINE 提前提醒相对截止时间提前触发；填 0 表示到期时提醒。

                

            

            
Org 闹钟属性名
              用于条目编辑器写入和后台扫描。只能使用字母、数字、下划线或连字符，三个名称不能重复。

WebDAV

          
从 WebDAV 文件夹读取全部 .org 文件并写回。电脑使用“OrglistWebDAV.cmd”；手机和电脑连接同一 Wi‑Fi 后，使用“启动Org清单-手机WebDAV.cmd”，再在手机打开窗口显示的地址。

          
直连模式
            
WebDAV 服务器必须主动允许跨域访问。

按需开启统计卡片。当前“计划完成率”以现存任务的 SCHEDULED/DEADLINE 为口径；被改期覆盖的旧计划无法追溯。

          

            
            
            
            
            
            
            
            
            
          

        

        

          
外部插件

          
导入本地 .js 插件或 .css 页面样式。插件保存在当前应用的 IndexedDB；不会随 Org 文件同步。

          
只安装你信任的插件。 JavaScript 插件与主程序拥有相同页面权限，可以读取当前打开的 Org 内容、本地设置，并调用当前平台已提供的桥接接口。Android 与 Windows 使用同一插件格式，但 Windows 桌面桥接功能不会自动出现在 Android。
